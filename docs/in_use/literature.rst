##################################
Publications using or citing TESPy
##################################

List of publications that builds on tespy sorted by date. The list is collected
from citations and google scholar search. The first section lists publications
that actually use the software, while the second one those that reference it.

If your work is missing, please open an issue or a pull request. The list is
maintained in :code:`docs/references.bib`.
